## ✏️ Messages are easier to edit

The goose's messages in **Settings** are now a proper list instead of one big text field.

- Click a message to edit it, or click **✕** to remove it.
- Type a new one in **Add a message…** and press **Enter**.
- **Reset to defaults** asks before it replaces your own messages.

## 💾 No more lost settings

Changed something in Settings and switched tabs or closed the window without saving? The goose now asks: **Save**, **Discard** or **Keep editing**.

## 🪿 Simpler, with fewer settings

- **Pause is gone.** In a meeting, use **Do not disturb** instead: the goose stays away, and your timer keeps running. Done for a while? Stop the session.
- **Time away counts as a break, automatically.** If you're away from your computer for at least a break's length (at lunch, or while the goose was waiting), that counts as your break, and the countdown starts fresh when you're back. The separate *"Away counts as break after"* setting is gone; it now simply follows your break length.

## 🐛 Fixes

- **Stopping a session now sends the goose away.** If the goose was asking for a break or napping, it now walks off, and the next session counts down normally.
- **No more black strips** around the pop-ups on some display scales.

## 🔧 Under the hood

The code is reorganised, and there are now automated tests for the timing rules. Every release runs them before it's built.

## Install

- **`TakeABreakGoose-Setup-1.4.0.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.4.0-portable.zip`**: just the app. Unzip it anywhere and run it.

If you already have 1.3.0, the Settings tab will tell you about this update.

The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.
