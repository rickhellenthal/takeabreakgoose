## 🪿 One goose for Windows and Mac

Under the hood, the Windows goose is now the same app as the Mac one. On Windows it works just like before: your settings, your shortcut and Start with Windows all carry over when you update. From now on, every improvement comes to both at once.

What you might notice:

- **A smaller download**: about a third smaller than before.
- **Clicks go right past the goose.** Only the goose itself, its speech bubble and its break card catch clicks; the empty space around them doesn't.
- **Opening the goose while it's already running** brings its window forward, instead of saying it's already running.

## 🍎 On a Mac

- Check boxes and buttons are the goose's own orange, instead of the accent colour picked in System Settings.
- Clicks go right past the goose here too, and the party hat is no longer cut off at the top.

## Install

On Windows:

- **`TakeABreakGoose-Setup-1.10.0.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.10.0-portable.zip`**: just the app. Unzip it anywhere and run it.

Works on Windows 10 and 11. If you already have the goose, the Settings tab will tell you about this update. The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.

On a Mac (macOS 12 or later):

- **`TakeABreakGoose-1.10.0-mac-apple-silicon.dmg`** for a Mac with an Apple chip (M1 or later), **`TakeABreakGoose-1.10.0-mac-intel.dmg`** for an Intel Mac.
- Open it and drag **Take a Break Goose** onto **Applications**, then open it from there.
- **"Take a Break Goose can't be opened"?** The app isn't signed by Apple, so macOS blocks it the first time. Open **Terminal** and run this once:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Take a Break Goose.app" && open "/Applications/Take a Break Goose.app"
  ```
