## 🍎 The goose comes to the Mac

Take a Break Goose now also runs on macOS: the same goose, focus sessions, naps, outfits and settings. It lives in the menu bar instead of the system tray, naps just above the Dock, and keeps away during calls.

The Mac version is an extra. It's made on Windows and we can't test it on a Mac ourselves, so use it with care: bugs are more likely than on Windows. Found one? Please [open an issue](https://github.com/rickhellenthal/takeabreakgoose/issues).

On Windows nothing changes: the goose works just like in 1.7.0.

## Install

On Windows:

- **`TakeABreakGoose-Setup-1.8.0.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.8.0-portable.zip`**: just the app. Unzip it anywhere and run it.

Works on Windows 10 and 11. If you already have the goose, the Settings tab will tell you about this update. The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.

On a Mac (macOS 12 or later):

- **`TakeABreakGoose-1.8.0-mac-apple-silicon.dmg`** for a Mac with an Apple chip (M1 or later), **`TakeABreakGoose-1.8.0-mac-intel.dmg`** for an Intel Mac.
- Open it and drag **Take a Break Goose** onto **Applications**, then open it from there.
- **"Take a Break Goose can't be opened"?** The app isn't signed by Apple, so macOS blocks it the first time. Open **Terminal** and run this once:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Take a Break Goose.app" && open "/Applications/Take a Break Goose.app"
  ```
