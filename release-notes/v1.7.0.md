## 📋 See the breaks you've taken

Once you've had a break, the running session shows **Breaks this session** at the bottom: when each break was, how long it lasted, and how it went.

- **Napped with the goose**: you took the break until it was over.
- **Ended early**: you cut it short.
- **Away from the computer**: time away that counted as a break.

The break you're on right now is shown on top, with how long it's been so far, and you can see the total too.

## 🎉 A goodbye that looks back

When a session reaches its end time, the goose now also tells you how it went, like *"You took three breaks along the way, about 20 minutes of rest."* No breaks at all? It'll gently point that out too.

## ⏱️ Breaks down to the second

The break length's **Other…** now has minutes and seconds, so quick eye breaks are possible, like looking away for 20 seconds every 20 minutes. Short pauses while you're reading don't count as a break, though: being away only counts once you've been gone for at least a minute.

## 🧠 The goose remembers your break length

The start card now starts with the break length you used last time, just like the break interval. Sessions that start automatically use it too, so the **Default break length** setting is gone. Your old default carries over.

## ✋ Finishing up comes first

When it's break time, **Let me finish up** is now the button next to **Okay, break time!**, and **Snooze** is the quieter link. Finishing up lets you save your work and then take your break, instead of putting it off for a while.

## 🛠️ Small things

- Clicking or tabbing into a number box on the start card selects the number, so you can type over it straight away.

## Install

- **`TakeABreakGoose-Setup-1.7.0.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.7.0-portable.zip`**: just the app. Unzip it anywhere and run it.

Works on Windows 10 and 11. If you already have the goose, the Settings tab will tell you about this update.

The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.
