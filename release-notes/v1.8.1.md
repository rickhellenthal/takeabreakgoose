## 🐛 Clicks while the goose walks

While a goose walked across the screen, clicks in the app's window only happened once it stopped walking. They now work right away.

## ✋ A goose that doesn't get forgotten

- **It comes back to check.** After **Let me finish up**, the goose waits at the edge of the screen. If you haven't clicked it after 2 minutes, it comes back to ask again, and you can choose **Let me finish up** as often as you need.
- **Time away counts while it waits.** Walked away while it peeked? If you were gone for at least your break length, that counts as your break, just like while it asks.

## Install

On Windows:

- **`TakeABreakGoose-Setup-1.8.1.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.8.1-portable.zip`**: just the app. Unzip it anywhere and run it.

Works on Windows 10 and 11. If you already have the goose, the Settings tab will tell you about this update. The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.

On a Mac (macOS 12 or later):

- **`TakeABreakGoose-1.8.1-mac-apple-silicon.dmg`** for a Mac with an Apple chip (M1 or later), **`TakeABreakGoose-1.8.1-mac-intel.dmg`** for an Intel Mac.
- Open it and drag **Take a Break Goose** onto **Applications**, then open it from there.
- **"Take a Break Goose can't be opened"?** The app isn't signed by Apple, so macOS blocks it the first time. Open **Terminal** and run this once:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Take a Break Goose.app" && open "/Applications/Take a Break Goose.app"
  ```
