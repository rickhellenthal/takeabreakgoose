## 🧪 A test of updating from inside the app

This is a test version, to try out updating the goose from inside the app.

- **Updates from inside the app**: when a new version is out, the goose tells you once, and you can update from its menu or the Settings tab.
- **Never in the middle of a break**, and a running focus session carries on after the update.
- **What's new** shows up after every update, in short.

## Install

This is a pre-release for testing.

On Windows: **`TakeABreakGoose-win-Setup.exe`**. The app isn't code-signed, so Windows SmartScreen may warn you the first time: click **More info**, then **Run anyway**.

On a Mac: **`TakeABreakGoose-osx-arm64-Setup.pkg`** for a Mac with an Apple chip, **`TakeABreakGoose-osx-x64-Setup.pkg`** for an Intel Mac. The installer isn't signed by Apple, so macOS blocks it the first time: **System Settings → Privacy & Security → Open Anyway**.
