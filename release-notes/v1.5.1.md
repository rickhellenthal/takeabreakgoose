## ✨ A small polish

When you start a focus session, the preset times are now the obvious pick. The option to type your own time is called **Other…** (it used to be *Custom*) and looks a bit quieter until you choose it. Nothing else changes.

## Install

- **`TakeABreakGoose-Setup-1.5.1.exe`**: run it to install or update. No admin rights are needed. If the goose is running, the installer asks to close it first.
- **`TakeABreakGoose-1.5.1-portable.zip`**: just the app. Unzip it anywhere and run it.

Works on Windows 10 and 11. Coming from 1.4.0 or older? Have a look at the [1.5.0 release](https://github.com/rickhellenthal/takeabreakgoose/releases/tag/v1.5.0): the goose now stays away during calls.

The app isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.
