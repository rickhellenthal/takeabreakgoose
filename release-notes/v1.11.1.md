## 🎮 Games stay in full-screen

- **No more being thrown out of your game**: since 1.9.0, a goose coming by could drop a game in full-screen back to the desktop. It leaves your game alone again.
- **In exclusive full-screen you won't see the goose**, just like before 1.9.0: nothing can be drawn on top of the game there. The goose waits until you leave the game. Want to see it while you play? Set your game to borderless full-screen (often called "Fullscreen Window").

## ⚙️ Calmer Settings

- **Shorter explanations**: one line at most, or none where the setting says it all.
- **Always up to date**: **Look for new versions** is gone, so the goose always lets you know when a new version is out. It only ever sends GitHub its own version number.

## 👋 Coming from 1.10.0 or older

Version 1.11.0 changed how the goose is installed, so moving to this one takes one manual step. After that, updates come by themselves.

- **On Windows**: uninstall the old goose first (*Settings → Apps → Installed apps*), then install this one. Your settings stay. Had the goose start with Windows? Turn **Start with Windows** on again in its Settings tab.
- **On a Mac**: open the installer; it installs over the old goose. Your settings stay.

## Install

Already on 1.11.0? The goose offers this update by itself.

On Windows: **`TakeABreakGoose-win-Setup.exe`**. No admin rights are needed. Or
**`TakeABreakGoose-win-Portable.zip`**: unzip it anywhere and run `Take a Break Goose.exe`.
The app isn't code-signed, so Windows SmartScreen may warn you the first time: click
**More info**, then **Run anyway**.

On a Mac (macOS 12 or later): **`TakeABreakGoose-osx-arm64-Setup.pkg`** for a Mac with an
Apple chip (M1 or later), **`TakeABreakGoose-osx-x64-Setup.pkg`** for an Intel Mac. The
installer isn't signed by Apple, so macOS blocks it the first time: **System Settings →
Privacy & Security → Open Anyway**. Still "can't be opened"? Open **Terminal** and run this once:

```bash
xattr -dr com.apple.quarantine "/Applications/Take a Break Goose.app" && open "/Applications/Take a Break Goose.app"
```

On Linux: **`TakeABreakGoose.AppImage`**. Make it executable (`chmod +x TakeABreakGoose.AppImage`)
and run it. It lives in the system tray, and works best in an X11 session.
